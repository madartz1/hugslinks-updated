# Featured HUGS Cards

Permanent visitor destination: https://hugslinks.com/featured-hug.html

The homepage panel, Cards page panel, and featured page all read featured-hug.json.
To feature the next card, change that single file and publish the site.
Update id, title, titleEs, description, descriptionEs, image, imageAlt, and cardUrl.
Use existing same-site image and card-page paths. Check the destination and artwork before publishing.
No public edit form or browser-only setting is used: the published file controls what all visitors see.

Use the permanent featured link on general postcards. Those postcards always introduce the latest feature.
Use a card's individual page on edition-specific postcards: that QR always opens that named card.
The delivered general featured postcard uses the permanent featured link and always opens the current feature.

Repeat each release:
1. Publish the finished card page, cover and preview media.
2. Update featured-hug.json.
3. Confirm the homepage, Cards page and permanent featured page show the new feature.
4. Share the permanent featured page. Make a fresh edition postcard only if its artwork or title changes.

These are additive files and small insertions in index.html and hugs-cards.html.
Keep all existing site files and redirects when publishing. The add-on ZIP is not a replacement for the whole site.
